# Factory Lens

Планировщик производства для Satisfactory с русскими и английскими названиями

Задайте выпуск в минуту и получите схему потоков, расход сырья, мощность и дробное количество зданий

## Возможности

- Минимум ресурсов, энергии или зданий
- Базовые и альтернативные рецепты, запреты и выбор рецепта через вершину графа
- Редкость ресурсов, чистота залежей, лимиты добычи и внешние поставки
- Конвейеры и трубы с расчётом параллельных линий, побочные продукты и возвратные потоки
- Крупные подписи потоков, цвета материалов и упрощённый вид графа
- Сравнение рецептов при одинаковом выпуске, изменения сырья, мощности и зданий
- Импорт открытых альтернатив из `.sav`, сохранение планов в JSON и передача ссылкой

Расчёт работает локально в браузере через HiGHS / WebAssembly, все данные и библиотеки входят в проект

## Локальный запуск

Нужен Python 3, сборка и установка npm-пакетов не требуются

Из папки проекта выполните:

```bash
python3 -m http.server 8000 --directory dist
```

В Windows можно заменить `python3` на `py`

Откройте [localhost:8000](http://localhost:8000), для остановки нажмите Ctrl+C

Приложение нужно открывать через HTTP, прямой запуск `dist/index.html` не подходит

## Тесты

Нужен Node.js 24, устанавливать зависимости не требуется

```bash
node --test tests/*.test.mjs
```

Дополнительные примеры `.sav` подключаются через `FACTORY_LENS_SAVE_FIXTURES`, без неё эти проверки пропускаются

## Особенности расчёта

- Здания считаются при 100% частоты, значение `4,3` означает производительность 4,3 машин
- Карточка производства отдельно показывает нормы одной машины и суммарные потоки участка
- Разгон, сомерслупы, генерация энергии, прессуризаторы скважин и физическое размещение не моделируются
- Мощность переменных машин усредняется, побочные продукты требуют потребителя или утилизации
- Преобразование сырья с SAM включается отдельно, по умолчанию используется обычная добыча

Планы хранятся в браузере, для резервной копии экспортируйте JSON

## Обновление

Распакуйте содержимое полного архива в папку проекта с заменой файлов, затем перезапустите локальный сервер и обновите страницу через Ctrl+F5

Для Wet Concrete на одну машину при 100% нормы составляют 120 известняка и 100 м³ воды на 80 бетона в минуту, цикл занимает 3 секунды

В сравнении рецептов расход ингредиентов приведён к одинаковому выпуску, а изменения сырья, мощности и зданий относятся ко всему плану
